# 境织个人 Alpha 产品决定

本文记录产品打磨访谈中已经确认的决定，作为后续规格与任务拆分的输入。它描述目标行为，不代表当前代码已经实现。

## 产品边界

- 境织是通用桌面上下文助手，不局限于伴学；个人 Alpha 首先服务于观看课程、培训、会议回放和技术演示等长内容的知识工作者。
- 核心闭环是：用户记录一段活动，随时追问“刚才发生了什么、为什么”，获得可追溯回答，并在结束后生成会话材料。
- 当前阶段只实现 Windows 桌面端，不实现移动端、手表、账户系统或云同步。
- 长期方向是跨设备个人上下文与生活助理；当前领域模型不得把来源硬编码为桌面专属概念。

## 会话与录制

- 只能由用户明确开始会话；自动化可以提醒，但不得自动录制。
- 开始前显示所有显示器的实时缩略图、系统声音与麦克风选择、预计存储量。默认选中全部显示器，并记住上次选择。
- 录制期间显示录制胶囊：状态、时长、显示器数量、音频状态、暂停、提问和结束。
- 暂停会同时停止屏幕、系统声音和麦克风，并在时间线上形成暂停区间。
- 音频开始前允许选择设备并查看输入电平。录制中不持续提示静音或低音量，只在设备拔出、设备消失、流停止或确认丢失数据等硬故障时通知。

## 主界面与时间线

- 主窗口首页是会话库，而不是单页录制器；当前会话置顶，并支持最近会话、搜索、筛选、固定和删除。
- 时间线采用横向多轨布局，至少包含关键帧缩略图、字幕片段、问答、暂停区间、音频缺口和校订事件。
- 时间线支持整段、五分钟、一分钟和秒级缩放；右侧详情区显示大图、完整字幕、问题和版本。
- 图片的主要可见位置是时间线。回答区域显示“使用了 N 张关键帧”等紧凑证据入口，点击后定位内部时间线，不尝试控制原始播放器。

## 提问、回答与证据

- 浮层负责即时提问；主窗口负责会话管理和深入回看。
- 用户触发提问快捷键时立即创建问题锚点，再允许其从 30 秒、2 分钟、5 分钟等范围中选择并慢慢输入问题。
- 支持文字和按住说话提问；语音先转成可编辑文字再提交，不实现唤醒词。
- 回答默认静音，用户可手动朗读。
- 每个回答必须持久化其实际使用的关键帧 ID、字幕版本 ID、模型连接、模型名称和推理配置。
- 回答可以补充通用知识，但必须区分“会话证据确认”“补充解释”和“无法确认”。
- 回答及证据必须可复现。字幕后续发生校订时不静默改写旧回答；用户可基于最新字幕生成新答案版本。
- 跨会话能力先做搜索，再由用户选择证据并让模型综合；当前阶段不提供无边界的全库聊天。

## 字幕与校订

- 当前阶段先稳定落地本地 Whisper，不直接实现 OpenAI 兼容转写；第三方转写以后通过独立适配器扩展。
- Whisper 原始字幕应尽快出现。主界面提供轻量、均衡、准确三档，并在高级设置中保留模型、设备、计算精度、语言和 VAD 参数。
- 首次使用进行本地样本测试，展示延迟、资源消耗和示例结果。
- 字幕校订是可选功能。关闭时只显示原始字幕，不出现“待校订”等状态。
- 开启后，原始字幕依次显示“识别中”“待校订”“已校订”；校订文本默认显示，改动短暂高亮，完整差异与所用模型按需查看。
- 用户编辑的字幕拥有最高优先级，不得被自动校订覆盖；校订可撤销。
- 校订每 15、30 或 60 秒批处理一次，默认采用 15–30 秒档；输入包括相邻字幕以及每个选中显示器的最新关键帧和最多两张高变化关键帧，并限制总图片数。
- 不根据置信度决定是否校订，因为专业术语可能被高置信度地识别错误。校订失败时继续使用原始字幕。
- 不区分“本地模型”和“远程模型”。用户配置并启用校订连接即视为授权，但界面必须说明发送的字幕、截图、频率和用量，并记录来源。
- 本阶段不实现自动术语表。

## 模型连接与任务路由

- 模型连接与模型角色分开配置，同一连接和模型可以复用于多个角色。
- 四个角色分别是：实用模型、字幕校订模型、即时问答模型、深度分析模型。
- 实用模型处理标题重命名、标签、章节候选和搜索改写；确定性任务继续由代码完成。
- 推理强度按任务设置，不使用单一全局值。产品层提供快速、均衡、深入档位；适配器只向支持该参数的服务发送映射后的字段。
- 校订使用最低或关闭推理，即时问答默认均衡，深度分析使用更高推理，实用任务使用最低推理。
- 每个角色可配置后备模型。同一连接内可自动后备；跨连接后备必须获得用户明确授权，并记录实际使用的连接、模型和原因。
- 校订失败回退原始 Whisper；实用模型失败使用确定性标题；深度分析失败进入可重试队列。

## 会话材料

- 总结和其他会话材料默认是自由 Markdown，不强制标题、章节或严格 JSON 结构。
- 最小持久化外壳只需内容、证据引用和可选模板标识；模板能力仅预留架构，本阶段不做模板编辑器或市场。
- 会话材料可编辑并保留版本；原始生成版本、再次生成版本和用户编辑版本均可追溯。
- 问答原文不可直接改写，用户可以追加笔记或生成新版本。
- 首次结束会话时询问“始终自动生成、每次询问、仅手动生成”，记住选择，并明确提示模型调用、发送内容和潜在费用。

## 数据、隐私与生命周期

- 会话库完全保存在本地。只有用户触发模型任务时，才向对应模型连接发送完成该任务所需的最小上下文。
- 默认在 30 天后自动清理整个未固定会话。首次引导说明该规则，在清理前 7 天和 1 天通知，清理后也通知。
- 自动清理先把整个会话移入本地回收区并保留 7 天；固定会话不参与自动清理。删除必须以完整会话为单位，避免证据链断裂。
- 单会话导出为 ZIP，包含 Markdown、字幕、关键帧、音频和证据索引；同时支持完整备份与恢复。PDF、Word 和平台专用导出以后通过插件扩展。
- 首次引导依次说明隐私与保留策略、模型连接、本地转写选择与性能、快捷键与录制确认，然后直接开始第一个会话。

## 个人 Alpha 验收边界

- 使用者完成至少 10 次真实长会话，单次 1–2 小时能够稳定采集、转写、提问和结束。
- 浮层问答、可见证据、崩溃恢复、自动清理与回收、导出恢复和资源指标可用。
- 不出现来源不明的敏感内容采集，所有模型调用和实际证据均可追溯。

## 实施优先级

1. 时间线关键帧缩略图。
2. 字幕版本持久化基础与小模型异步校订；版本基础是校订安全落地的前置条件。
3. 持久化问题实际使用的字幕版本和关键帧。
4. 问题锚点。
5. 在时间线上高亮被引用的图片和字幕。
6. 回答区域展示证据入口。
7. 点击证据定位时间线。
8. 模型角色、推理强度、后备与来源记录。

## 当前实现差距

- 当前主界面仍是单页录制器，没有会话库、录制胶囊或多轨时间线。
- 当前只采集主显示器，尚未实现显示器选择和默认全选。
- 当前问题上下文只保存时间范围，不保存实际关键帧和字幕 ID。
- 当前字幕只有单一文本版本，没有原始、校订和用户编辑之间的版本关系。
- 当前总结要求严格 JSON，与自由 Markdown 会话材料决定冲突。
- 当前只有一个模型配置，没有连接与角色分离、推理强度、后备或调用来源记录。
- 当前没有自动清理、回收区、导出恢复或跨会话检索界面。
