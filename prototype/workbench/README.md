# PROTOTYPE — 境织工作台视觉方向

一次性界面原型，用于回答：“境织的会话库、证据时间线、详情区和录制胶囊应该如何组织？”

包含三种结构不同的方案，通过 `?variant=A|B|C` 或页面底部切换器比较。

运行：

```powershell
uv run python -m http.server 4173 --directory prototype/workbench
```

然后打开 <http://localhost:4173/?variant=A>。

此目录只属于 `prototype/workbench-visual-directions` 原型分支，不得直接合入正式应用。
